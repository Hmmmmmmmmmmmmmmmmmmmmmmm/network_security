// Capabilities
What's Under The Hood
01
Smart Model Selection
Compares the current run against all historical MLflow runs. If a previous run produced better results, retrains locally with its exact parameters — no remote download required.
02
Hyperparameter Tuning
GridSearchCV across the top 5 candidate models. Param grids are YAML-configured, with type-safe casting from MLflow string params back to native Python types.
03
Experiment Tracking
Every run logged to DagShub via MLflow. Metrics, params, and tags persisted remotely. The pipeline always starts from the global best — not just the latest run.
04
KNN Imputation
Missing value imputation via KNNImputer (k=3, uniform weights) fitted during transformation and bundled with the model in a NetworkModel wrapper for inference.
05
Drift Detection
Data validation checks column counts and schema on every run. Drift reports generated as YAML artifacts alongside the validated train/test splits.
06
Live Prediction API
Upload a CSV via the /predict endpoint. The NetworkModel transforms and scores in one call. Results returned as an HTML table and saved as a timestamped CSV artifact.
